# tinyticker
Crypto Price Tracker
![image](https://github.com/user-attachments/assets/423e38d9-7b6a-4f76-974b-a1904cfb3c87)

Coded in HTML/ CSS / JS 
Coins are added as you search.
Displays at most 5 coins.
When the maximum number of coins is reached, coins get removed from the top to accomodate new ones.
